# Examples for `@sebastienrousseau/jsdoc-config`

This directory contains runnable examples demonstrating how to consume and extend `@sebastienrousseau/jsdoc-config`.

## Available Examples

- [`basic.js`](basic.js): Basic consumption of the standard configuration.
- [`advanced.js`](advanced.js): Custom extension and rule overrides.

## Running Examples

```bash
node examples/basic.js
node examples/advanced.js
```
